# Phase 1 · Stakeholder Interaction Matrices

Built as an interactive page per site; each row links to the stakeholder's persona view and to the inbox messages generated in their voice. Columns: **What they ask me for · Channel · Cadence · System/report they use directly · Decisions they make · Great vs poor response from me.**

# The Engineering Head's Handbook — Companion Repository

Templates, labs, the golden-path service and scenario packs for
**The Engineering Head's Handbook** (Kumar Abhishek Shahi, The Final Leap, 2026).
Everline Group is fictional; all data synthetic and seeded.

## Setup
```bash
pip install -r requirements.txt          # Python 3.12+
python labs/run_labs.py                  # runs every lab (budget, DORA, capacity, incident sim, …)
cd goldenpath && python -m pytest tests && python ci_checks.py   # R12: the reference service
```

## Map (repo ↔ responsibilities)
- `templates/` — 20+ one-page artifacts: strategy, ADR, build-vs-buy, strangler plan, hiring loop,
  attrition diagnosis, OKR plan, red-program reset, SLO policy, audit response, exception form,
  budget cut options, vendor scorecard, postmortem, on-call standard, AI adoption policy,
  board pack, DD checklist, crisis pack, 90-day plan.
- `goldenpath/` — R12/R28: the reference service (API + idempotency + tests + 5 CI gates + IaC stub).
- `design-docs/` — R7/R8: six design briefs + **flawed-loyalty-v2.md** (five planted flaws) + answer key.
- `labs/` — budget model, DORA generator+metrics, FinOps units, capacity math, attrition diagnosis, incident timeline.
- `incident-sim/` — R46 tabletop: timeline + five injects + facilitation notes.
- `interview-prep/` — question bank, transcript excerpts, mock-loop rubrics.
- `metrics-lab/`, `budget-lab/` — pointers: both are generated by `labs/labs_core.py` (lab_dora / lab_budget); adapt the generators to your own exports.

## Hands-on practice workspace — Everline Hub — Engineering Head Workspace

`site/` holds a static, offline-capable training simulation that accompanies *The Engineering Head's Handbook*: realistic enterprise applications with seeded data, a simulated inbox and clock, persona switching ("View as"), an "Explain this screen" panel and graded missions mapped to the book. **Every page has a ▶ Practice Now button**: a step-by-step guide, a live template/calculator pre-filled with the workspace's numbers, formulas, data-collection sources, how to produce the report, the value to the organisation, and how to do it in the AI age.

- **Run locally:** open `site/index.html` in a browser — no server or install needed.
- **Publish:** Settings → Pages → Source: **GitHub Actions**. The included workflow (`.github/workflows/pages.yml`) deploys `site/` on every push to `main` that changes it.
- Details: `site/README.md` (missions index, data reset/export) and `site/docs/BUILD-BIBLE.md` (decisions, canon placement, QA).

> Training simulation. All organisations, people and data are fictional.
